# Raptor Motion Lab

Распакуйте весь ZIP. Откройте start.py в Pydroid 3, нажмите Run.
Браузер откроется автоматически; если нет — перейдите на напечатанный локальный адрес http://127.0.0.1:8765/ на том же телефоне.
Не закрывайте Pydroid во время просмотра. Python использует только стандартную библиотеку; Интернет и pip не нужны. Требуется браузер с WebGL 2.

На компьютере: python3 start.py.

Выберите исходный Action или созданное отдельно движение. Пауза, перемотка, скорость, повтор, общий вид и крупный план руля. Камеру можно вращать мышью/пальцем; масштаб — щипком или колесом мыши.

Новые движения: плавный разгон/торможение, прогрессивное руление, геометрия Аккермана, индивидуальные углы вращения колёс по длине дуги. Это воспроизводимые процедурные движения просмотрщика, не записанные автором Blender Actions и не физическая симуляция подвески. При повторе автомобиль возвращается в начало траектории.

Внутри: оригинальный .blend и 60 PNG, оптимизированная GLB-копия с текстурами и всеми 8 исходными Actions, программа и разбор модели. На реальном Android/Pydroid работа не проверялась; производительность зависит от устройства.
