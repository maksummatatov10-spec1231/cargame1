# Y Bot · Motion Laboratory

Офлайн-программа для просмотра персонажа Y Bot и его исходных анимаций вместе с оптимизированной моделью Ford Raptor.

## Запуск
Распакуйте архив как папку и запустите:
```bash
python start.py
```
Pydroid 3: откройте папку, запустите `start.py`, затем откройте указанный адрес в браузере. Зависимости через pip не нужны.

## Что внутри
- 5 исходных FBX-анимаций, конвертированных без замены движения: Breathing Idle, Walking, Running, Backward Right Turn, Y Bot.
- `raptor.glb` — та же оптимизированная машина из Raptor Animation Lab.
- Новая сцена «Посадка в Raptor»: 12 секунд, рука к двери, открытие оригинальной двери, перенос ног, посадка, закрытие.
- Прозрачный кузов, скелет, камеры, скорость и покадровый ползунок.

## Важные ограничения
Посадка — авторская скелетная постановка и прототип, не motion capture. Положения таза, ног и рук измерены по реальной геометрии сиденья, пола, потолка и руля. Автоматическая проверка 18 опорных суставов в `reports/collision_scan.json` показывает опорные контакты и возможные локальные проникновения; это не сертификат полного отсутствия пересечений всех треугольников. Для финальной игровой анимации её нужно вручную доработать в Blender и протестировать на целевом устройстве.
